# Методика «Баланс Емоційних Світів» — матеріал із семи слайдів

**Статус:** уточнено за повною презентацією «ЗАВДАННЯ_МЕТОДИКА_БАЛАНС_ЕМОЦІЙ_pptx.pdf» (7 слайдів); не наукова валідація методики.

## Призначення

Методика позиціонується як спосіб оцінки й самоаналізу емоційних станів для визначення того, у якому емоційному «світі» людина перебуває більшу частину часу. У заявленій моделі є п’ять категорій емоційних станів — «світів», які відображають різні рівні емоційного тонусу й життєдіяльності. Завдання — краще зрозуміти інтенсивність і частоту переживань, знайти способи підтримання емоційного балансу.

## Інструкція зі слайдів

1. Учасник отримує **35 станів** у довільному порядку.
2. Оцінює кожен від **1** («майже не відчуваю») до **7** («часто це відчуваю»).
3. Переносить оцінки в групи відповідних «світів».
4. Підсумовує бали в кожному «світі».
5. Інтерпретація результатів використовується для усвідомлення стану та вибору стратегій підтримки.

### П'ять «світів»: повний ключ (слайд 7)

| Світ | Стани |
| --- | --- |
| 1 | Любов, щастя, ентузіазм, радість, вдячність, натхнення, легкість |
| 2 | Задоволення, спокій, оптимізм, впевненість, надія, зосередженість, довіра |
| 3 | Байдужість, втома, нудьга, нейтральність, рутина, відсутність натхнення, скептицизм |
| 4 | Злість, роздратування, фрустрація, заздрість, обурення, цинізм, неприязнь |
| 5 | Страх, тривога, паніка, відчай, депресія, самотність, безпорадність |

Кожен світ містить 7 станів; арифметичний діапазон суми — 7–49 балів. Порівнюються суми п'яти світів; клінічних порогів презентація не встановлює.

## Застереження

Слайди не містять даних про авторство, психометричну валідність, норми чи порогові значення. Це самозвіт про частоту/суб’єктивне переживання, а не діагноз. Слова «депресія», «паніка» та інші назви станів у списку не слід трактувати як клінічну діагностику.
